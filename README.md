# ⚡ Spark Rehab

**Spark Rehab** is a modern web application designed to streamline rehabilitation services and patient management. Built with **React**, **Vite**, and **Tailwind CSS**, it offers a premium, accessible user interface optimized for healthcare professionals and patients alike.

---

## ✨ Features

- **Built with Vite**: Blazing fast development and optimized production builds.
- **Robust TypeScript**: Strict type safety ensures a reliable and maintainable codebase.
- **Accessible Design**: Premium UI components powered by shadcn/ui, focused on accessibility and ease of use.
- **Responsive Layout**: Seamlessly transitions between mobile, tablet, and desktop views.
- **Optimized Performance**: High-performance React architecture for a smooth user experience.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build System**: Vite
- **Styling**: Tailwind CSS & shadcn/ui
- **Language**: TypeScript
- **State Management**: Modern React hooks

---

## 💻 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Shabber10/spark-rehab-site.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
